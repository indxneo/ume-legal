# Ume legal pages

The privacy policy for Ume, an iPhone app for remembering birthdays and the dates that matter.
Published with GitHub Pages at https://indxneo.github.io/ume-legal/.

- `privacy.html`: the privacy policy. It must match what the app actually does: the app's repository documents
  what each feature sends (see its `CLAUDE.md` and `docs/PRODUCT.md`). Change the effective date with every edit.
- `index.html`, `style.css`: plain static pages in the app's plum blossom colors, light and dark. No scripts and
  nothing loaded from other sites.
